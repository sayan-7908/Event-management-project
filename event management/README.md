# SKF Events - Event Management (PHP + MySQL)

1. Install XAMPP and start Apache and MySQL.
2. Copy this `event-management` folder into `C:\xampp\htdocs\`.
3. Open http://localhost/phpmyadmin, click Import, choose `database.sql`, and run it.
4. Open http://localhost/event-management/ in your browser.

Logins
- Admin: http://localhost/event-management/admin/login.php  (admin / admin123)
- Student: register a new account, or use roll no 36442724010 / pass123

Database settings are in `db.php` (user root, empty password, database event_db).
